商談・導入を進める

相手の課題を聞いて、次に決めることを整理する。

初回の商談では、お客様がどんな集客をしていて、何に困っているかを聞くことから始めます。分からない質問や判断に迷う点は、相談用のメモに残しましょう。

必要なところから

  1. 提案前に聞く5つのこと
  2. 本部に相談するためのメモ
  3. 商談を終える前に
  4. 導入後、最初に確認すること
  5. 結果を説明する文例
  6. 今日やること

提案前に聞く5つのこと

  1. どんなお客様を増やしたいですか。
  2. 今のお問い合わせは、何を見て来ることが多いですか。
  3. お客様から、契約や購入の前によく聞かれることは何ですか。
  4. 御社の強みや対応条件は、どのページで確認できますか。
  5. 今回、何が分かれば取り組むかどうか判断できますか。

そのうえで、AIの回答と公式情報を見比べ、確認や改善が必要な点を整理します。十分に伝わっている点も含めて、取り組む必要性を考えます。

本部に相談するためのメモ

提案書が完成していなくても、聞かれたことと困っている点を書き出すところから準備できます。

お客様への約束と、これから相談する内容を分けて書きましょう。顧客情報や会話記録を渡す場合は、共有できる範囲と相談先を確認します。

  1. 01顧客の話を聞く
  2. 02相談メモを整理
  3. 03本部へ確認・相談
  4. 04役割と次の行動を決める
  5. 05顧客に返答する

相談方法と利用できる支援は、ご契約時の案内をご確認ください。

商談を終える前に

今回確認できたこと、まだ分からないこと、お互いが次にすることを確認します。お客様が検討を進めるために何が必要か、一つ決めて持ち帰りましょう。

対象の情報会社・サービス・サイト・確認する質問
現状確認日・AIの回答・公式情報との違い
顧客への説明何を確認し、どこを改善するか

AIでの紹介、サイトへの訪問、問い合わせ、受注は、分けて記録します。変化があったときは「何が変わったか」と「まだ分からないこと」をお客様に伝えます。

結果を説明する文例

今回は、〇月〇日に「□□」という質問で確認しました。前回と比べて△△の変化が見られました。問い合わせ・受注への影響は、引き続き確認が必要です。次は◇◇を見直し、次回の確認結果を共有します。
