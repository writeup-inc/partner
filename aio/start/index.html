はじめの一歩

まずは、自社で試して、1社に声をかける。

「誰に提案すればよいか分からない」「説明する自信がまだない」。そんなときは、自社を題材に確かめるところから始めましょう。気づいたことを一つ言葉にできれば、お客様との会話の入口になります。

必要なところから

  1. 自社を題材に、説明の材料を作る
  2. 最初に声をかける1社を選ぶ
  3. 1社分の準備シート
  4. 今日やること

自社を題材に、説明の材料を作る

お客様が会社を探すとき、どんな質問をするでしょうか。自社のサービス、地域、得意分野をもとに、まず一つ考えてみてください。

質問の例：

「〇〇地域で、△△を相談できる会社を選ぶとき、何を確認すればよいですか？」

実際にAIに聞き、回答と自社の公式サイトを見比べます。自社が紹介されるかに加え、強みや対応条件が正しく伝わっているかも確認します。

公式情報と違う点・足りない点（記入欄）
お客様に話せそうな気づき（記入欄）

一度の回答で結論を出さず、質問と条件を残しましょう。すでに必要な情報が伝わっている場合は、その点も記録します。

最初に声をかける1社を選ぶ

既存のお客様、以前見積もりを出した会社、最近仕事の話をした知人。まずは、連絡する理由を説明できる相手から考えます。

接点が少ない場合は、地域と業種を一つに絞ります。そのうえで、知人や協業先に紹介を頼めるか、公開されている企業情報から課題を考えられるかを確認します。

連絡できる相手はいますか？

接点がある

既存客・過去の相談先から選ぶ

接点がほぼない

地域・業種を一つに絞る
紹介を頼む・公開情報で候補を探す
